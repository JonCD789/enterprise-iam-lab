# Enterprise Identity & Access Management Lab

## Project Overview

This project simulates the design and implementation of an enterprise Identity and Access Management (IAM) environment for a fictional healthcare organization, Northwind Health Systems.

The goal is to demonstrate practical IAM skills including:

- Active Directory Administration
- Microsoft Entra ID
- Identity Lifecycle Management
- Role-Based Access Control (RBAC)
- PowerShell Automation
- Microsoft Graph API
- Identity Governance
- Access Reviews
- Group Policy
- Audit Reporting
